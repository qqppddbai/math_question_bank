# 数学题库管理系统（MVP）

面向中学数学老师的**本地**题库工具：题目管理 · 搜索筛选 · 批量导入 · 手动组卷 · 试卷导出 · 学生错题档案。

- 纯本地运行，不联网、不登录、不上传
- 数据全部保存在 `data/` 目录，换电脑拷过去就能用
- 中文界面，KaTeX 实时渲染 LaTeX 公式

## 功能一览

| 模块 | 主要功能 |
|---|---|
| 🏠 首页概览 | 题库/试卷/学生/回收站统计，题型·难度·年级分布 |
| 📚 题目管理 | 新增、编辑、软删除、图片上传，支持 6 种题型 |
| 🔍 搜索筛选 | 关键词全文 + 多条件组合 + 知识点/标签多选 + 时间范围 + 批量操作 |
| 📥 批量导入 | 粘贴或上传 JSON 数组，校验 → 查重 → 一键入库 |
| 📝 手动组卷 | 从题库挑题、分大题、设分值、调整顺序、存卷 |
| 📤 试卷导出 | Word (.docx) / HTML（可打印 PDF）/ Markdown，可含答案、解析、图片 |
| 👨‍🎓 学生档案 | 学生信息、错题收录（必须关联题库题目）、学习图片上传 |
| 🗑️ 回收站 | 题目与试卷的软删除还原、批量彻底删除、清空 |
| ⚙️ 系统设置 | 题库 JSON 导出、整库 ZIP 备份、图片清理、运行信息 |

## 环境要求

- Python **3.11+**
- 操作系统：Windows / macOS / Linux
- 浏览器：Chrome / Edge / Firefox 均可

## 安装

```bash
# 1) 建虚拟环境（推荐）
python -m venv .venv

# 2) 激活
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3) 安装依赖
pip install -r requirements.txt
