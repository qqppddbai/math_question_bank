# 数学题库管理系统

面向中学数学老师的**本地**题库工具：题目管理 · 搜索筛选 · 批量导入 · 手动组卷 · 试卷导出 · 学生错题档案。

- 🏠 **纯本地运行** —— 不联网、不登录、不上传，数据全部保存在 `data/` 目录
- 🇨🇳 **全中文界面** —— 无需懂编程，双击即可使用
- 🧮 **LaTeX 公式** —— 界面用 KaTeX 实时渲染，Word 导出为**原生可编辑公式（OMML）**
- 💾 **数据主权归用户** —— 拷走 `data/` 目录即可完整迁移

## 功能一览

| 模块 | 主要功能 |
|---|---|
| 🏠 **首页概览** | 题库/试卷/学生/回收站统计，题型·难度·年级分布 |
| 📚 **题目管理** | 新增、编辑、软删除、图片上传，支持 6 种题型 |
| 🔍 **搜索筛选** | 关键词全文 + 多条件组合 + 知识点/标签多选 + 时间范围 + 批量操作 |
| 📥 **批量导入** | 粘贴或上传 JSON 数组，自动校验 → 查重 → 一键入库 |
| 📝 **手动组卷** | 从题库挑题、分大题、设分值、调整顺序、存卷 |
| 📤 **试卷导出** | Word / HTML / Markdown，可含答案、解析、图片；Word 导出为**原生公式** |
| 👨‍🎓 **学生档案** | 学生信息、错题收录（关联题库原题）、学习图片、错题集导出 |
| 🗑️ **回收站** | 题目与试卷软删除还原、批量彻底删除、清空 |
| ⚙️ **系统设置** | 题库 JSON 导出、整库 ZIP 备份、孤儿图片清理、运行信息 |

## 环境要求

- **Python 3.11+**
- **Microsoft Word 或 WPS**（用于打开导出的 `.docx`；如需导出**原生公式**，需要 Office 提供 `MML2OMML.XSL`，通常已随 Office 安装）
- 操作系统：**Windows / macOS / Linux**
- 浏览器：Chrome / Edge / Firefox 均可

> 大多数情况下你**不需要安装任何东西**就能使用，除非你的电脑完全没有 Python。

## 安装

```bash
# 1) 建虚拟环境（强烈推荐）
python -m venv .venv

# 2) 激活
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3) 安装依赖
pip install -r requirements.txt
```

`requirements.txt` 内容：

```
streamlit>=1.36
SQLAlchemy>=2.0
python-docx>=1.1
Pillow>=10.0
latex2mathml>=3.77
lxml>=5.0
```

> **关于 Word 原生公式**：程序会尝试加载 `MML2OMML.XSL`（Office 自带），如果找不到，会自动回退到第三方库 `mathml2omml`。你可以在 Office 安装目录中搜索该文件（如 `C:\Program Files\Microsoft Office\root\Office16\MML2OMML.XSL`），复制到项目根目录下即可获得最佳公式转换效果。

## 运行

```bash
streamlit run app.py
```

Windows 用户也可以**双击项目根目录的 `run.bat`**。

浏览器会自动打开 <http://localhost:8501>。若端口被占用：

```bash
streamlit run app.py --server.port 8502
```

关闭程序：在终端按 `Ctrl + C`。

## 各模块使用说明

### 🏠 首页概览

打开应用后的第一眼，展示题库的**整体情况**：

- 题库题目总数、试卷数、学生数、回收站中已删除题数
- 题型分布、难度分布、年级分布（表格形式）

新装应用时题库是空的，会提示你到「📥 批量导入」或「📚 题目管理」开始录入。

---

### 📚 题目管理

题库的核心页面。

#### 新增 / 编辑题目

点右上角「➕ 新增题目」，弹出编辑表单，依次填写：

| 字段 | 说明 |
|---|---|
| **题型** | 单选题 / 多选题 / 填空题 / 解答题 / 判断题 / 作图题 |
| **年级** | 初一 ~ 高三 |
| **章节** | 自由文本，如"导数"、"立体几何" |
| **难度** | 1~5 星 |
| **题干** | 含 LaTeX；右侧有**实时预览** |
| **选项** | 选择题才显示，固定 A~D 四个 |
| **答案 / 解析** | 含 LaTeX，解析区有实时预览 |
| **来源** | 如"2023年新课标全国Ⅱ卷" |
| **知识点** | 逗号分隔，如 `极值点,分类讨论` |
| **标签** | 逗号分隔，如 `高考真题,新高考II卷` |
| **图片** | 支持上传 png / jpg / webp / gif，单张 ≤ 5MB |

#### LaTeX 书写要点

- 行内公式：`$x^2$` → 显示 *x²*
- 独立公式：`$$\int_0^1 x\,dx$$` → 居中显示
- **不要**用 `\( ... \)` 或 `\[ ... \]`（KaTeX 不识别）

#### 卡片阅读视图

每道题的卡片按以下顺序展示：

```
┌────────────────────────────────────────────┬────────────┐
│ 来源 xxx  难度 ★★★☆☆  年级 xxx  章节 xxx  │ ✏️ 编辑    │
│ 知识点 xxx  标签 xxx                       │ 🗑️ 删除    │
│ ────────────────────────────────────────── │            │
│ 题干（公式渲染）                            │            │
│ A. xxx  B. xxx  C. xxx  D. xxx             │            │
│ [缩略图]                                    │            │
└────────────────────────────────────────────┴────────────┘
 ▸ 📖 查看答案与解析
```

**删除**为软删除，题目会进入「🗑️ 回收站」，可随时还原。

---

### 🔍 搜索筛选

**精确定位**题库里的题。

- **关键词**：匹配题干、答案、解析、来源、标签、知识点、章节
- **多条件组合**：题型、年级、章节、来源、难度、知识点、标签，各条件为**同时满足（AND）**
- **多选逻辑**：同一条件内多个值之间为**满足任意一个（OR）**
- **按创建时间**：可指定一个日期区间
- **排序**：最近更新 / 最早更新 / 最近创建 / 最早创建 / 难度高→低 / 难度低→高

结果以**卡片列表**呈现（与题目管理一致），右侧「☐ 选择」按钮可勾选多道题。

选中后在页面底部出现**批量操作条**：

| 操作 | 说明 |
|---|---|
| ➕ 加标签 | 为选中题目统一追加标签 |
| ➖ 移除标签 | 为选中题目统一移除指定标签 |
| 📤 导出为 JSON | 导出选中题为标准 JSON，可再次导入 |
| 🗑️ 删除选中 | 批量软删除 |

> 翻页或改变筛选条件时，已选会**自动清空**，避免误操作。

### 📥 批量导入

把一段 JSON 数组一次导入多道题。

#### 操作步骤

1. 切到「📋 粘贴文本」标签，或切到「📁 上传文件」上传 `.json` 文件
2. 点「🔍 解析并预览」
3. 在结果表里检查每条题的状态：
   - ✅ **正常**：可直接入库
   - ⚠️ **重复**：与库内已有题题干相同
   - ⚠️ **提醒**：选择题选项少于 2 个等
   - ❌ **错误**：题干为空、题型非法、难度非法
4. 确认无误后点「✅ 导入 N 道题」

#### 导入规则

- **只有**题干为空、题型非法、难度非法会被**拒绝入库**
- 其他字段缺失会用默认值填充（题型默认"解答题"，难度默认 3）
- 勾选"跳过与库内重复的题目"时，重复题会被自动跳过

格式说明见下文「[导入格式](#导入格式)」。

---

### 📝 手动组卷

从题库选题目，组合成一份试卷。

#### 页面结构（从上到下）

1. **试卷基本信息**：标题、副标题、考试时长
2. **试卷结构**：按大题分组，显示每道题的分值，可上下移动 / 删除
3. **从题库选题**：筛选条件 + 卡片列表，勾选加到指定大题

#### 操作要点

- 新建试卷时会有一个默认大题"一、单选题"，标题可改
- 可通过「➕ 添加大题」新增第二个、第三个大题
- 分值可单独设置，总分实时汇总
- 保存后可在列表中编辑，或到「📤 试卷导出」导出文件

### 📤 试卷导出

把试卷导出为 **Word / HTML / Markdown**。

#### 导出选项

| 选项 | 说明 |
|---|---|
| **文件格式** | Word (.docx) / HTML / Markdown |
| **包含答案** | 是否在导出文件里显示答案 |
| **包含解析** | 是否显示解析 |
| **包含题目图片** | 是否把题目配图嵌入文件 |
| **答案位置** | 「每题后」或「卷末统一」 |

#### 各格式特性

| 格式 | 公式 | 图片 | 备注 |
|---|---|---|---|
| **Word** | **原生 OMML 公式**（可在 Word 内编辑） | 居中嵌入 | 推荐用于二次编辑、打印 |
| **HTML** | KaTeX 渲染 | base64 内嵌 | 单文件可打印成 PDF |
| **Markdown** | LaTeX 原文 | base64 内嵌 | 适合用 Typora/Obsidian 阅读 |

#### 如何得到 PDF

导出 **HTML** 格式 → 双击用浏览器打开 → `Ctrl + P` → 目标打印机选「另存为 PDF」→ 保存。

#### 文件落盘

每次导出的文件会同时在 `data/exports/` 里留一份副本，文件名带时间戳，方便反复使用。

### 👨‍🎓 学生档案

为每位学生建档，长期跟踪薄弱环节。

#### 学生信息

- 姓名、班级、年级、备注
- 支持搜索和班级筛选
- 支持软删除（在页面底部「🗑️ 已删除学生」中还原）

#### 错题收录

1. 进学生详情页，点「➕ 添加错题」
2. 从题库中筛选并选中一道题
3. 填写：学生错答、错因分析、掌握程度（❌ 未掌握 / ⚠️ 部分掌握 / ✅ 基本掌握 / 🌟 已掌握）
4. 保存后系统自动记录**题干快照**（题库原题日后被修改也不影响历史）

同一学生对同一道题只允许一条错题记录。

#### 学习图片

- **错题级图片**：挂在某道错题下，如学生手写解答照片
- **学生级图片**：不挂错题，如试卷扫描件、笔记照片

图片保存在 `data/student_files/`，删除记录时磁盘文件也会一并清理。

#### 导出学生档案

点「📤 导出学生档案（错题 + 学习图片）」，可导出：

- 学生基本信息
- 所有错题的题干、答案、错答、错因、掌握程度、配图
- 学生级学习图片

格式同样支持 Word / HTML / Markdown。

### 🗑️ 回收站

**题目**和**试卷**被删除后先进入这里，可以恢复。

| 操作 | 说明 |
|---|---|
| ♻️ 还原选中 | 从回收站恢复到原位置 |
| ❌ 彻底删除选中 | 不可恢复；被试卷引用的题目会被自动拦截 |
| 🧹 清空回收站 | 一键清空，被引用的题目自动跳过 |

**为什么题目被彻底删除时会失败？**

如果题目被某份试卷引用，直接删除会导致试卷结构损坏。请先到「📝 手动组卷」编辑相关试卷、移除该题并保存，再回来删除。

### ⚙️ 系统设置

#### 📦 备份 / 导出

| 功能 | 用途 |

| **题库 JSON** | 只导出题目，格式与「批量导入」完全兼容，用于分享或迁移 |

扫描 `data/images/` 下所有未被任何题目引用的图片（题目被彻底删除或图片被替换后遗留的），可选择批量删除。

## 导入格式
不支持其它形式，可将pdf、word、latex等文件交由ai处理后录入。

标准 **JSON 数组**：

```json
[
  {
    "grade": "高三",
    "chapter": "导数",
    "knowledge": "不等式证明,极值点,分类讨论",
    "qtype": "解答题",
    "difficulty": 5,
    "stem": "(1) 证明：当 $0<x<1$ 时，$x-x^2<\\sin x<x$；\n(2) 已知函数 $f(x)=\\cos ax-\\ln(1-x^2)$，若 $x=0$ 是 $f(x)$ 的极大值点，求 $a$ 的取值范围。",
    "options": "",
    "answer": "(1) 证明见解析；\n(2) $(-\\infty,-\\sqrt{2})\\cup(\\sqrt{2},+\\infty)$",
    "analysis": "构造 $F(x)=x-\\sin x$ 求导证明。",
    "source": "2023年新课标全国Ⅱ卷",
    "tags": "高考真题,新高考II卷"
  }
]
```

### 字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| `stem` | ✅ | 题干 |
| `qtype` | 建议填 | 单选题 / 多选题 / 填空题 / 解答题 / 判断题 / 作图题，默认"解答题" |
| `difficulty` | 建议填 | 1~5 整数，默认 3 |
| `options` | 选择题必填 | 多行文本：`"A. xxx\nB. yyy\nC. zzz\nD. www"` |
| `grade` | 建议填 | 初一 ~ 高三 |
| `chapter` | 建议填 | 如"导数" |
| `knowledge` | 选填 | 逗号分隔 |
| `tags` | 选填 | 逗号分隔 |
| `answer` / `analysis` | 选填 | 答案与解析 |
| `source` | 选填 | 来源 |

### 易错点

- **LaTeX 里的反斜杠要双重转义**：JSON 中 `\sin` 必须写成 `\\sin`
- **换行用 `\n`**，不要按回车
- **最外层必须是 `[ ]`**
- 若整个字符串是空串 `""`，表示该字段为空

如果你是用 Python 的 `json.dumps(..., ensure_ascii=False)` 生成的，则不会有转义问题。

## 数据备份与恢复

### 三种备份方式

| 方式 | 适用场景 | 操作 |
|---|---|---|
| **题库 JSON** | 分享题库、迁移到新环境 | 「⚙️ 系统设置 → 备份 / 导出 → 生成题库 JSON」 |
| **整库 ZIP** | 灾难恢复、整机迁移 | 「⚙️ 系统设置 → 备份 / 导出 → 生成整库备份」 |
| **手动拷贝 `data/`** | 最省事、最完整 | 用文件管理器直接复制整个 `data/` 目录 |

### 恢复方式

**推荐**：把 `data/` 目录整个替换到目标电脑。

**若使用 ZIP 备份**：按「⚙️ 系统设置 → 恢复」页面的指引操作：
1. 关闭 Streamlit（终端按 `Ctrl + C`）
2. 替换 `data/images/` 和 `data/student_files/`
3. 删除 `data/mathbank.db`
4. 重启应用，用「📥 批量导入」导入 `data.json` 里的题目
5. 学生和试卷数据需手工重建（MVP 限制）

### 清空所有数据

关闭程序 → 删除 `data/mathbank.db` → 重启应用。

## 取舍

- **单机单用户**：无登录、无权限、无并发控制；同一时间只能一人使用
- **SQLite 数据库**：适合万级以内题目；超大题库建议换 PostgreSQL
- **图片不自动压缩**：单张 ≤ 5MB，原图存储
- **Word 公式依赖 Office 的 XSLT**：本机没装 Office 时回退到第三方库，转换成功率会低一些
- **不支持 Excel 导入**：JSON 表达力更强，避免 CSV 换行/编码的坑
- **无拖拽排序**：题目顺序用 ⬆️⬇️ 按钮调整
- **不自动清理回收站**：需手动清空
- **PDF 通过浏览器打印**：不直接生成 PDF 文件
